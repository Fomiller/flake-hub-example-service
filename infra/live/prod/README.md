# infra/live/prod

The prod environment. Three files live here and nothing else:

- `account.hcl` — the environment name and region
- `terragrunt.stack.hcl` — which stacks this environment gets
- this README

Everything else you see in this directory is generated by `terragrunt stack
run` from `infra/stacks/` and `infra/units/`, and is gitignored. Do not edit a
unit here — edit it under `infra/units/`.

`terragrunt.stack.hcl` here declares no stacks. The only stack this repo has is
`aws/common`, and "common" means once per account — dev applies it and prod
does not.

```sh
just plan prod
just apply prod
```
